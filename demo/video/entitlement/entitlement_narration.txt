This demo shows the reusable Onto2AI workflow for designing, testing, and publishing a domain package. Entitlement is the worked example, and the final proof is the onto2ai entitlement package.

Application teams often begin with code models, constraints, and API contracts. Without a shared semantic source, those artifacts drift and every team rebuilds domain meaning differently.

The Onto2AI method starts with RDF. We define domain concepts, relationships, restrictions, enumerations, and documentation before committing to an implementation model.

For entitlement, the ontology connects users, policy groups, policies, row filter rules, column mask rules, and the protected database, table, and column context.

Onto2AI Modeller loads the RDF into a modelling workspace where designers inspect the ontology graph, review class details, and refine relationships before generation.

Ontology View, UML, and application code model views make inheritance, cardinality, required properties, and enumeration choices visible before they become application contracts.

Onto2AI MCP turns ontology intent into aligned schema JSON, query context, Neo4j constraints, and an application code model. Pydantic is one supported target, not the goal itself.

Ontology Mode validates RDF syntax, URI conventions, and package mirrors. Schema Mode checks generated artifacts and verifies the selected ontology in stagingdb.

Dataset Mode creates an isolated disposable database, applies constraints, loads representative entitlement instances, validates application topology, and rejects ontology-only runtime content.

Release Mode reruns the live gates, aligns versions, builds the wheel and source distribution with uv, and inspects their contents before it can report success.

The final package contains the RDF ontology, generated schema artifacts, application code model, and reusable smoke test, independently consumable from the modelling workbench.

Entitlement is only the example. The reusable method is to model meaning, inspect and refine it, generate aligned artifacts, test schema and runtime behavior, and publish an independent domain package.
